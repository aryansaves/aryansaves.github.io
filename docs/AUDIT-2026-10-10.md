# Performance and security inspection — October 10, 2026

Two user-requested GPT-6 Sol subagents independently inspected performance and security. This is a source/dependency review, not a penetration test or measured performance profile. No dependency fixes, commit, push, or deployment were made.

## Performance

| Priority | Evidence | Impact and suggested follow-up |
| --- | --- | --- |
| Medium | `src/app/layout.tsx` loads Super Adorable as TTF; exported font is 266,084 bytes. Papernotes WOFF2 is 12,964 bytes. | The display font is used immediately in the masthead. Consider WOFF2 compression/subsetting if its license permits; verify appearance and measure load impact. |
| Low–medium | `NotebookTurn.tsx` calls `draw()` directly on each drag pointermove, updating full-page clip paths and several styles. | High-frequency pointer input may produce excess work. Coalesce drag draws with requestAnimationFrame and profile before claiming a speed improvement. |
| Low | `page.tsx` always renders the 48,040-byte cat SVG; CSS hides it on narrow screens and for reduced motion. | Hidden images can still download. Verify with a cold network trace; consider media-based resource selection while preserving the intentional animation. |

## Security

The applicable finding is a **low-severity development-server information disclosure**. `package.json` pins Next.js 16.3.5 and starts `next dev` on `0.0.0.0`. [GHSA-39w2-rjm5-chcv](https://github.com/advisories/GHSA-39w2-rjm5-chcv) affects Next.js 16.0.0 through versions before 16.3.8: a malicious website visited while development is running can read development data through its MCP endpoint. Update Next.js and the matching ESLint configuration to a patched version. Bind development to localhost by default unless LAN access is needed; binding alone does not fix the cross-origin vulnerability.

`npm audit --omit=dev` also reports advisories in Next.js, Sharp 0.35.4, and source-map-js 1.2.1. The reviewed production attack conditions appear absent: this site exports static files, has unoptimized images, and has no runtime Next.js server, image optimizer, `next/og` route, dynamic SVG input, or untrusted source-map input. The full audit adds a development lint dependency chain involving braces/micromatch/fast-glob, without an identified untrusted glob input. These remain dependency maintenance findings; no exploit of the static production site was demonstrated.

Source inspection found no exposed credential or direct XSS sink. The deployment workflow mentioned in older docs is absent from this checkout; deployment configuration was not verified remotely.
